# Contributing

Constructive corrections and architecture feedback are welcome.

## Contribution principles

Contributions must:

- Use fictional and sanitized data
- Explain architecture rationale and trade-offs
- Cite authoritative sources where relevant
- Avoid copying copyrighted diagrams or proprietary documents
- Update related documentation and diagrams together
- Clearly state assumptions, constraints and limitations
- Contain no customer or employer-confidential information

## Proposed workflow

1. Open an issue for substantial architecture or structural changes.
2. Create a focused branch.
3. Make one logically related set of changes.
4. Review the complete diff.
5. Open a pull request with validation details.
6. Address review comments before merging.
