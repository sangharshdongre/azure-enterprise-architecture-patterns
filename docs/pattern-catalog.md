# 📚 Architecture Pattern Catalog

This catalog lists the Azure enterprise architecture patterns maintained in
this repository.

## Status Definitions

| Status | Meaning |
|---|---|
| Proposed | Initial idea awaiting definition |
| Draft | Requirements or architecture are being developed |
| Reviewed | Documentation and architecture have completed repository review |
| Validated | The reference implementation has completed defined validation |
| Deprecated | The pattern should not be used for new work |
