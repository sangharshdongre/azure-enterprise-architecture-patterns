## Documentation Principles

References support technical claims but do not replace architecture reasoning.

Each pattern must distinguish:

- Microsoft-documented service behavior
- Microsoft recommendations
- Pattern-specific design decisions
- Organization-specific requirements
- Assumptions that require validation
